# 1.5.0 音画候选 · 2026-10-22

本轮目标是正常游玩时可直接辨认的音画升级。上一版只加入微弱高频，贴图平均通道差不足 1.2/255，几乎没有改变视觉组织；本轮改为实际替换主要表面，并让表面材质、局部受光、接触关系与空间声音共同起作用。

## 体验与版本

在仓库根目录运行 `python serve.py 8139`，打开 `http://127.0.0.1:8139/`。对照页为 `http://127.0.0.1:8139/reports/av-v1.5/`，可拖动切换三篇入口画面，比较五条声床中的代表素材，并查看真实按键走入公寓后的画面。入口页底部标注 **1.5.0 音画候选**。

分支 `codex/v1.5.0-audiovisual`；本轮基线 `f669c15`，回退标签 `codex/av-v1.4-before-upgrade`。更早的 1.3.1 基线标签仍为 `codex/av-baseline-20261021`。本候选未替换 itch.io，也未构建 Windows 安装包。回看旧版时在另一工作目录检出标签，避免重置现有工作区。

## 视觉方向与实现

保留老公寓、旧澡堂、乡野夜路及既有低多边形场景。室内以象牙灰、霉绿、暗红棕和旧织物为主，户外用冷月光与暖灯笼形成方向感。没有把概念图贴在屏幕上，也没有更换玩法场景。

- 新下载的 **Z-Image Turbo** 真实生成 11 张 768×768 材质源，经共同色板匹配与镜像周期化制成 512×512 表面及高度图，实际覆盖 16 个材质槽：灰泥、天花、两种墙纸、绿砖、白砖、地砖、门板、深木、浅木、木地板、神龛木、窗帘、泥路、树皮、草地。保留可见的中尺度剥落、印花、接缝、木纹和地面颗粒，不再限制到接近不可见的高频残差。
- 使用 Phong 材质的凹凸与受光表现区分釉面、木材和粗糙墙面；高度图仅是从生成图亮度构建的近似，不声称为真实测量的物理高度或 PBR 扫描。纹理支持线性过滤、mipmap 与最多 4× anisotropy。原有非替换材质沿用原流程。
- Blender 从固定基线 GLB 以 24 条半球射线、0.65 米范围烘焙局部遮蔽到 COLOR_0，凹角与接触处变暗。原几何、节点、交互属性和碰撞体不变；没有提高模型三角形数。
- 走廊与澡堂荧光灯改成有方向性的局部光池，每篇室内选择一盏灯生成软阴影。阴影贴图桌面 512、触屏 256，静态刷新 5 Hz，门动画立即刷新；反射与主场景分别刷新，防止镜子渲染消耗主场景的请求。公寓环境补光经过调整，避免上半墙和天花变成无信息的黑块。
- 增加低透明度湿面与少量空气微粒，均不参与交互射线与碰撞。粒子只在 playing 时更新。夜路增加周期高云层次，收小月盘和月晕。
- 基础颗粒 .035 → .009、色差 .8 → .22、暗角 .44 → .32，扫描线 .12 → .035、dither .008 → .002；仍保留压力变化。新桌面用户默认 renderScale .8，触屏默认 .45；尊重已有设置，不覆盖用户已存的 .6/.45 选择。若沿用旧设置，可在“渲染颗粒度”选择“清晰”。

生成节点、提示、固定种子与实际 prompt_id 保存在 `tools/av/generate_v15.py` 及 `tools/av/sources-v15/*.json`。源 PNG/FLAC 随分支保留，权重不进仓库。Z-Image 使用本机 bf16 checkpoint，载入为 fp8_e4m3fn 以适配显存。Qwen Image、Trellis 与 Pixal3D 虽已在本机发现，本轮没有把其未验证输出计入成果。

模型与工作流来源：[Comfy-Org Z-Image Turbo](https://huggingface.co/Comfy-Org/z_image_turbo)、[官方示例](https://comfyanonymous.github.io/ComfyUI_examples/z_image/)。Blender ↔ ComfyUI 往返桥沿用 [1.4 说明](av_iteration_v1.4.md)，本轮重点在实际运行资产与渲染，而非桥接演示。

## 声音方向与实现

Stable Audio Open 新生成公寓走廊、澡堂荧光声场各一份 16 秒源；复用上一版已保留的窗雨、远水和野风生成源。五条环境床以原床 .25、新生成层 .85 的幅度系数重混（不是能量占比），交叠加窗循环、滤波、去 DC 并约束峰值。音乐 main 音量 .5 → .34，为环境与交互留出空间；音乐构成和故事提示不变。OGG 与 MP3 同步更新。

混响不再三篇通用：公寓 1.65 秒、澡堂 3.3 秒、户外 .48 秒，并配不同湿声量。窗雨来自走廊窗户位置；澡堂滴水与远水具有固定位置及距离衰减，随玩家移动和转头变化。独立 window 声道在进屋后仍保留，下一轮沿用同一声道，结束时由 stopAll 清理。

音频数值见 `reports/av-v1.5/audio.json`；接缝阈值是工程筛查，不能替代听感。对照页试听的是单条环境素材，完整游戏还有音乐、HRTF 方位、距离衰减与实时混响。

## 验证与边界

- 静态结构：`verify_v15.py` 比较基线与最终 GLB，三篇分别保留 107 / 33 / 28 个玩法节点的世界矩阵与属性、37 / 12 / 17 个碰撞体边界；三角形数维持 8764 / 4716 / 5710。COLOR_0 实际存在于最终 primitive，而非只写出烘焙日志。16 张高度图边缘周期一致，13 份生成源有 SHA256 记录。
- GLB 契约检查通过；door 仍有原有的“高于建议 6000、低于硬上限 9000”警告。根项目 `src/validate_project.py` 通过。
- 实际渲染：`after/result.json` 由正式 Edge / Direct3D11 / **RTX 3050 Laptop** 采样，包含 62 个基础纹理、16 个高度材质和实际着色网格计数，非 placeholder，无缺失音频或页面异常。每篇约 50 帧的短采样用于发现明显问题，不代表完整路线、极端负载或物理手机表现。软件渲染的开销显著更高，不能据此计算前后 GPU 性能提升。
- 实际行为：`route/{before,after}/result.json` 记录实际 WASD、鼠标拖动与 E，从起点行走至门口、开门、穿过碰撞边界、进入公寓并触发“找到三张字条”。没有 teleport。只覆盖首个公寓入口，不声称完整通关。两版停止位置略有误差。
- 音频：121 个文件通过格式、响度与循环数值检查。`audio-lifecycle.json` 验证最终输出、暂停中音量/解锁、静音恢复与快切；隔离浏览器内绕过最终 gate 的变异确实被静音断言拒绝。
- 打包浏览器交互检查使用最终 ZIP 的独立解压目录，结果位于 `reports/qa/release-1.5.0/web/result.json`。WebKit 测试环境无 AudioContext，只验证 MP3 引用和交互，不能声称 Safari 实机音频通过。触屏是浏览器模拟，非物理手机；此类交互验收有辅助定位，与上述正常入口路线分开记录。

仍待真人试听、完整游玩、移动设备实测与艺术取舍确认。不把工程检查通过写成主观表现已被用户接受。

最终网页包 `Sangeng-1.5.0-web.zip`：36,970,202 字节、368 个运行文件，SHA256 `63c79fc937fabc84ab25702ad61bb984aaaeaebb6ad27fc3c7bf902dafb4d3ce`。该包的六种浏览器配置已通过检查，当前运行源文件逐一匹配打包 manifest。RTX 3050 的三个入口短采样中位帧间隔约 6.8–7.0 ms；仅报告采样条件，不将其外推为全程最低帧率。

## 复现

已有 Python 3.11 / numpy / Pillow / ffmpeg、Blender 5.2 和 ComfyUI 环境即可使用。默认系统 python 没有 numpy，应选择已安装该依赖的解释器。

```powershell
python tools/av/generate_v15.py     # 缺少源文件时调用本机 Z-Image；已有源则复用
python tools/av/prepare_v15.py      # 从保留源重做颜色/高度图，不调用模型
python tools/av/audio_v15.py        # 已有声音源时只重做后期
python tools/build_audio_fallbacks.py
blender -b --factory-startup --python tools/av/bake_v15_ao.py
python tools/av/verify_v15.py
python tools/build_web.py
```

脚本中的模型需位于本机 ComfyUI 目录；客户端仅允许 localhost。烘焙自动从 Git 基线导出输入，重复运行不会累加遮蔽；不会打开或覆盖用户现有 Blender 工程。
