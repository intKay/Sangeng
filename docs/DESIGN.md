# 三更 · 三个心理恐怖 demo 设计文档

一句话：三个 5–10 分钟的浏览器第一人称心理恐怖短篇，共用一套 PS1 时代低保真 3D 引擎；建模、贴图、音效与音乐全部为原创程序化资产。

合集名：**《三更》**（SANGENG — Three Watches）。入口 `index.html`。

## 技术总览

- three.js r160（已本地 vendor，见 `vendor/three/three.module.js`），WebGL2，纯静态文件；
- 美术：低多边形（每场景 4k–9k 三角面）、128–512px 程序化/手绘感贴图、指数雾、顶点级明暗、抖动（dither）、扫描线、胶片颗粒、色差、低分辨率渲染再放大；
- 音频：OGG 音效 / 环境 / 音乐 + WebAudio 实时合成的心跳、呼吸、耳鸣、低通滤波、空间声像；
- 语言：简体中文界面与字幕；无外部网络请求、无外部字体、无版权素材；
- 内容提示：心理恐怖、幽闭空间、闪烁画面、死亡意象；**没有血腥画面，不靠巨响做 jump scare**。

## 共同规则

- 玩家：步行 2.4 m/s，Shift 快走 4.0 m/s，眼高 1.62 m，碰撞半径 0.32 m；不可跳跃、不可攀爬；所有关卡地面 y = 0（平地）。
- 输入：WASD 移动，鼠标视角，E 交互，F 手电（仅《门后》），Shift 快走，Esc 暂停，点击开始后锁定鼠标。
- HUD 极简：中心小点准星、交互提示、一行目标、字幕（可关）。
- 单局 5–10 分钟；无存档；死亡就地重试；标题页可调鼠标灵敏度、主音量、字幕开关、像素颗粒度（渲染倍率 0.45 / 0.6 / 0.8）、全屏。
- 每个 demo 三个页面状态：标题页（海报 + 内容提示）→ 游戏 → 结局/死亡页（重试 / 返回入口）。

## 一更《门后》DOOR

- 主题：回家、等待、没说出口的话。
- 场景：2000 年前后中国城市老公寓五楼走廊 + 503 室。
- 前提：你每年回来一次。今年，门没锁。
- 目标：在 503 里找到三张字条，打开卧室门。
- 循环：每拿到一张字条，灯灭，你回到走廊开端；走廊和屋内发生细微变化（更多污渍、门开着、椅子挪了位置、灯管坏掉）。
- 手电：F 开关；电量约 120 秒，捡电池 +60 秒；低电量闪烁；黑暗会加快「心悸」。
- 实体：第三轮出现。她**只在你没看她时移动**；你看住她时她静止。被碰到 → 本轮从头开始（保留字条进度）。
- 节奏：第一轮探索 → 第二轮异变 → 第三轮追逐 → 卧室结局。
- 结局：卧室椅子上坐着「她」，床上有一封信。读完信 → 结束。
- 时长：6–8 分钟。

## 二更《镜中》MIRROR

- 主题：自我、替身、留下的人。
- 场景：90 年代公共澡堂更衣室（瓷砖、长镜、储物柜、长凳、水汽、日光灯）。
- 前提：澡堂夜里还有人。镜子里的人比你早到。
- 目标：三个回合，每回合让现实与镜中一致（每回合 2–3 个差异）。
- 机制：镜面实时渲染「另一间房」；玩家改变现实物品（毛巾、阀门、灯开关、凳子、柜门、收音机、模特）让两边一致；对齐后回合结束，镜中身影靠近一步。
- 代价：每完成一回合，镜中身影靠近一步；每次无效/错误交互也让它靠近一步；五步到身后 → 死亡。
- 结局：第三次对齐后，镜中人站在你背后。镜面碎裂 → 结束。
- 时长：5–7 分钟。

## 三更《夜路》NIGHTROAD

- 主题：送葬、乡野志怪、回头。
- 场景：深夜乡道：土路、稻田、电线杆、纸钱、田埂、土地庙。
- 前提：你送完葬，走夜路回家。身后多了一个人。
- 目标：点亮沿途五盏纸灯笼，走到土地庙。
- 机制：纸人在身后跟随；看向它时它静止；连续注视超过约 2.5 秒会「夺灯」（最近一盏灯熄灭并扣理智），所以只能短促回望。
- 点灯：E 点亮；点灯会定住它 6 秒，并成为重生点。
- 死亡：被碰到 → 回到上一盏已点亮的灯。
- 结局：庙前上香；可选择「回头看」或「不回头」，两段不同结尾文字。
- 时长：7–10 分钟。

## 目录结构

```

  index.html                 合集入口（海报卡片）
  README.md                  运行方式、操作、资产说明
  serve.py                   本地静态服务器
  engine/                    共享引擎（渲染/后处理/玩家/交互/音频/UI/镜子）
  games/door|mirror|nightroad/  三个 demo 的页面、配置与玩法代码
  assets/models/             Blender 导出的 GLB
  assets/textures/           贴图 + manifest.json
  assets/audio/              音效/环境/音乐 + 每游戏 manifest.json
  assets/art/                海报、印章、favicon
  tools/                     blender / audio / art 可复现生成脚本
  docs/                      设计、资产、音频、美术、引擎接口文档
  reports/                   QA 截图与自检报告
```

## 验收标准（Lead 终验）

1. 打开入口页能看到三个 demo 卡片与内容提示；点进任一个能进入标题页并开始游戏。
2. 每个 demo 有：第一人称移动与碰撞、可用交互、目标提示、完整开始→玩法→结局流程、可重试。
3. 每个场景使用 Blender 导出的 GLB 几何（不是纯代码方块），且贴图、材质命名与规格一致。
4. 每个 demo 有独立音乐 loop、环境 loop、至少 12 个音效，以及随危险变化的心跳/紧张层。
5. 后处理（颗粒/扫描线/暗角/色差/低分辨率）生效，理智/危险状态能改变画面。
6. 本地服务器下无 404、无控制台报错；Playwright 截图与自动冒烟测试通过。
