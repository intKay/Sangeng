# v1.0.1 验证范围

日期：2026-10-19（Asia/Taipei）。Windows、Chrome/Playwright、本地源码服务器与 EXE 内嵌服务器。

修复前，AudioContext running、音频 ready 和缓冲区存在，但实测主混音峰值为 0；根因为 BufferSource 没有连接 GainNode。v1.0.1 已补齐该连接。

## 通过项目

- 三篇用真实 E 触发：门后开门、镜中拿起毛巾、夜路点亮第一盏灯。
- 门后真实 F 关/开手电；三篇真实 Esc、设置、音量滑杆、返回及继续。
- 三篇长按 E 不会合上刚打开的测试信纸，松开再按可合上。
- 隔离几何探针验证隐藏物件不会挡住可见交互物，当前提示可刷新。
- 三篇 Web Audio 主混音峰值分别约 0.141、0.157、0.110，缺失音频 0；有信号不等于人耳混音验收。
- EXE 内嵌 205 个文件经 HTTP 逐字节核对网页 ZIP；目录入口、JS MIME、HEAD、404、路径穿越与 Host 防护、拒绝 POST 均通过。
- 页面没有 JavaScript error；仍有 three.js `useLegacyLights` 弃用 warning。

原始机器结果：[运行时回归](../reports/qa/v1.0.1-runtime.json)、[分发服务核对](../reports/qa/release-package-check.json)。

测试用调试放置将玩家移到物件附近，实际交互使用真实键盘和按钮。没有把这种放置当成正常路线可达性测试。

## 未覆盖与现有限制

本轮没有重新逐关完整通关、真人听感/鼠标手感、异机、远端托管 iframe 或移动端验收。启动器正常界面的自动打开/关闭流程没有做原生 UI 自动化；已实际运行同一 EXE 的无窗口服务模式并验证三篇。

已知观感限制包括镜面偏暗、部分灯管材质自发光未随灯开关熄灭等；暂无存档与移动端适配。Windows EXE 未签名、未内置浏览器内核。
