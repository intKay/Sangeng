# 1.7.0 三篇美术返工候选

本轮覆盖《门后》《镜中》《夜路》，固定基线为 1.6 提交 `8afbad8`。目标是让器物构造、材料身份、生活尺度与受光共同改善画面。整体保留九十年代中国生活空间、低多边形和褪色记忆的方向。当前是内部审看候选，未获得用户审美接受，也未替换 itch.io 或 1.3.1 稳定发行。

运行 `python serve.py 8139`，打开 `http://127.0.0.1:8139/reports/av-v1.7/` 查看三篇各五个同机位前后对照，以及实际游戏输出的声音 A/B。直接从首页进入三个短篇即可体验本轮运行版本。

## 三篇具体变更

| 篇目 | 构造与材料 | 受光与空间关系 |
|---|---|---|
| 门后 | 厨房台面围绕真实凹入水槽开口；床垫和枕头倒角、被面有折叠和垂边；缝纫机使用旧漆铁件、空心轮圈与轮辐 | 保留 1.6 的旧纸、漆木和布料分工；床边增加局部光，缝纫机台灯随后段卧室提示启用，避免整件成为黑色剪影 |
| 镜中 | 洗手台盆与长凳搪瓷盆使用有厚度的中空壳；铁柜改为背板、侧板、底板与搁板，开放柜门后能看到内部 | 绿瓷砖恢复约 25 cm 分格，减少迷彩色块；铁柜锈迹集中在边缘、把手与通风处；水垢靠近潮湿下沿和浴室门 |
| 夜路 | 灰褐土路有不齐边缘和车辙；草锥替换为成簇草叶，方条田埂改为土垄；土地庙使用灰瓦与旧木 | 移除原有重复的方向光，按可见月亮方向设置冷月光与弱天空填充；降低携行灯和庙前光晕，让暖光承担指路作用 |

三篇都实际修改了 GLB。最终原始模型三角面数分别为 10,462、5,532、6,404；《门后》硬上限从 10,000 调至 11,000，《门后》《镜中》超过建议目标的警告保留，未通过降低校验标准隐藏警告。实际渲染面数包含裁剪、镜面和阴影通道，不能与原始模型面数直接比较。

新增五种材质身份：旧瓷釉、磨损钢、漆铁、灰瓦、踩实土路。共重新处理 14 种表面，材质清单现有 70 项，30 项带 512×512 高度图。高度图相对两边逐像素闭合；做旧另在生产 shader 按几何坐标放置，柜门打开时锈迹随柜门移动。静态局部遮蔽使用 24 条射线、0.65 m 邻域，并限制最暗值，避免把接触处统一涂黑。

## 审看与返修

遵循 [三篇审美门槛](art_direction_v1.7.md)，逐篇观察全景和近景。中间版本被拒收的具体问题包括：夜路出现大块偏蓝平面、室外高光发塑料感、缝纫机在卧室提示后仍是黑色剪影。排查时分别隔离凹凸、高光、雾与旧方向光；移除旧方向光并调整月光后重新审看，没有把单个潜在原因写成未经测量的确定结论。缝纫机通过实际灯光位置、目标与功率检查，再提高局部台灯功率解决可读性。最终截图使用实际运行素材，不对截图额外调色。

固定截图为生产 renderer、1440×900、正常眼高、辅助摆位与冻结时间。卧室两机位使用后段实际灯光提示检查材料；1.6 基线也应用对应提示。此类截图能检查构图和受光，不能证明正常游玩流程。内部审看不等于用户审美接受，仍保留有棱角的低多边形器物和风格化夜间黑位。

## 声音

本轮未生成新声音，也未宣称新模型生成成功。ComfyUI 8188 在本轮检查时不可用，图像处理复用此前仓库保留的 Z-Image 源，结合 Blender 几何与确定性后处理。

声音调整发生在实际播放链路：门后混响 1.4 s / wet 0.22，镜中 2.6 s / wet 0.36；降低雨、电视、荧光灯、滴水、风、虫鸣与远处犬吠的部分层次，以及三篇音乐底层音量，避免声音糊成同一层。夜路室外混响保持 0.48 s / wet 0.07。重试与周期触发分支也采用对应混音值。

`audio/before` 与 `audio/after` 是主音量 0.5、固定随机种子、每篇开场约十秒的最终 WebAudio 总线实录，经 Opus 录制转为 MP3。它们是可试听样本，不是原始音效替代品；信号指标只证明样本有效，不证明听感提升或全篇无问题。真人耳机试听尚待完成。

本候选实际执行结果：上述三篇 GLB 校验、15 对同机位、三条正常输入短路线、三篇辅助内容回归、声音生命周期与隔离变异检查、六种 Web 配置均通过；对照页的 15 个机位切换、三篇 A/B 播放互斥与 390 px 布局也已在浏览器检查。静态比对确认原有 169 个玩法节点变换与 66 个碰撞边界保留。根项目数据校验通过，未将私人根目录内容提交到公开仓库。

最终 Web ZIP：`dist/web/Sangeng-1.7.0-web.zip`，43,074,627 字节，433 个运行文件；SHA-256：`ea69f055e12d4c6199f801b4af14040dc3fa395acf067977772aaf89528db107`。此包是本地候选构建，未上传为正式 Release。

复现顺序：Python 3.11 + NumPy/Pillow 执行 `build_v17_surfaces.py`；独立后台 Blender 执行三篇构建脚本；第一次将未烘焙 GLB 传给 `bake_v17_ao.py --refresh`，以后单篇重建只替换对应 `model-before` 原件再烘焙，避免重复烘焙；启动服务运行上述实际浏览器检查。比较基线需另用 `git archive 8afbad8` 导出的独立目录服务。
