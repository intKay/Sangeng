# 三篇完整返工目标

本轮覆盖《门后》《镜中》《夜路》，1.6 为固定比较基线。整体仍是九十年代中国生活空间的低多边形、褪色记忆；不把三篇统一染成同一种脏绿。

| 篇目 | 必须改善的审美关系 | 拒收反例 |
|---|---|---|
| 门后 | 公寓的入口、起居、厨房、卧室都有材料分工与生活尺度；床褥与近景器物摆脱硬盒子 | 只改客厅、卧室仍是方块床；水槽贴着实心盖板；木柜一律新木纹 |
| 镜中 | 潮湿旧澡堂：瓷釉与水垢、掉漆铁柜、搪瓷器物有区别；镜内差异保持清晰，长凳与台盆构造可信 | 绿色像迷彩、台盆像金属饼、柜门打开后仍是实心墙；亮地砖压过镜面 |
| 夜路 | 灰褐土路连接田地、草丛与树，冷月光塑形、暖灯笼指路；土地庙构造与积灰有来源 | 白色平板公路、草地像花毯、锥形草、树干发白、整场平光与重复贴花 |

每篇至少五个固定正常眼高视角（包含近景与远景）与 1.6 对照。逐篇审看材料身份、纹理尺度、做旧来源、光线层次与画面主次；任一明显反例返工。模型三篇均要有与问题对应的实际变更，共用贴图替换不算三篇完成。

声音先核对实际播放链路、空间与画面关系，再决定是否重混；不得靠加音量、加噪声制造变化。所有新声音需给出可试听前后样本，暂停/静音/恢复验证到最终输出。

游戏结构与输入规则保持，碰撞与交互 ID 不随美术返工漂移；如果为可见性修正物件位置，必须列出具体对象和原因，并验证拾取与剧情。脚本/静态检查、辅助摆位内容回归、正常路线、真人审美接受分别记录。

保留独立 Git 分支和基线标签，不覆盖线上版本。本页记录制作目标；实际变更、审看与验证边界见 [1.7 制作说明](av_iteration_v1.7.md)。
