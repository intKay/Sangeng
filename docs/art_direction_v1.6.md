# 旧屋美术返工目标 · 2026-10-22

用户已拒绝 1.5 的审美结果。其素材与技术验收不等于质感提升，本轮不沿用“替换材质数量”作为成果标准。

## 明确的问题

1. 规则黑白绿棋盘地砖抢走注意力，改变了原先灰褐小砖的年代与气质。
2. 同一新木纹覆盖门、家具、地板，失去了木材种类、使用方式和磨损差别。
3. 窗帘与地毯共用材质，导致大面积重复花纹；暖水瓶使用木纹，材料身份错误。
4. 墙纸花纹清晰新净、重复可见；灰泥被简单提亮，缺少漏水来源、边缘沉积和生活痕迹。
5. 较亮环境光摊平室内，灯具、墙面、家具缺少清楚的主次；粒子和反光不能补偿这些问题。

## 美术方向

1990 年代被长期使用、维护有限的中国公寓。灰褐小砖、褪色米灰纸、褪色棕漆木、泛灰织物、黄褐水痕与少量霉绿。生活痕迹来自材料和使用关系，不靠全屏噪声或均匀撒污点。保留原来的压抑与克制，不把居室做成新装修的复古主题房。

## 必须通过的审看门槛

- **材料身份**：地毯、窗帘、木地板、门板、家具、暖水瓶能分别成立，不共用不合适的纹理；干燥墙纸与织物没有塑料高光。
- **尺度**：砖、木板、纸面花纹与正常眼高下的门框、暖水瓶一致；没有明显棋盘、镜像蝴蝶纹或大幅重复标记抢眼。
- **做旧因果**：漏水附近可见水痕与沉积，墙根与角落更积灰；手接触和行走位置的磨损方式不同；保留较干净的留白，避免整面均匀脏。
- **灯光层次**：室内暖灯为主，窗边有限冷色；物件轮廓、接触关系和表面变化可读，墙顶不能出现失去信息的大片死黑，也不能用高环境光抹平体积。
- **画面主次**：第一眼仍看见路、门、桌椅与生活物件；花纹、污渍、湿面和颗粒服从它们。室内没有无来源的水坑或装饰性闪点。
- **真实视角**：走廊、入屋、厨房、窗边、门口、书柜与沙发七个机位都要检查，保留 1.4 / 1.5 / 本轮的固定机位对照；正常操作入屋单独验证。不能只选一张“最好看”的截图。
