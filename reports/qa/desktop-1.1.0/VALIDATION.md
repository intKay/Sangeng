# v1.1.0 桌面分发验收

日期：2026-10-19，Windows 11 x64，本机定向自动化验收。

## 诊断与方案

用户补充症状为“浏览器打开无图片”。旧 ZIP 的本地 CRC 通过，SHA-256 与 v1.0.1 远端附件元数据一致。未取得原始下载文件与具体打开步骤，不能确认是 HTML 打开方式、资源路径还是其他客户端因素。

采用 Electron 44.9.0 内置 Chromium 152，保留 Three.js/Web Audio。使用 secure/standard 自定义协议从 ASAR 读取白名单资源，并明确 MIME；没有本机浏览器调用、HTTP 监听或远端资源依赖。renderer 关闭 Node、启用 contextIsolation 和 sandbox，拒绝外部导航和新窗口。

## 已验证

- NSIS 安装 EXE 实际静默安装到隔离目录，退出码 0；随后从已安装的 Sangeng.exe 验收。最终安装版与便携版约 128 MB，均未签名。
- 三篇入口、WebGL2、每篇 50/50 张纹理、模型加载通过；音频缺失 0，AudioContext running，主混音输出峰值非零。测量不等于人耳听感验收。
- 实际点击开始，鼠标锁定成功；实际 E 触发门后门状态 false→true、镜中物件状态 floor→hook、夜路计数 0→1。QA 使用游戏调试入口定位到真实物件附近，再通过键盘触发，未冒称自然游玩通关。
- 门后手电 F 开关、三篇 Esc 暂停/继续、音量滑杆、返回入口通过。页面错误与请求失败均为 0。安装后的窗口正常关闭。
- 单文件便携 EXE 在普通临时目录直接运行，自动解包并打开内置桌面窗口；入口 4 张图片均成功解码，门后 50 张纹理和音频加载通过。关闭后进程检查未见 Sangeng 残留；CDP 关闭时测试客户端在最终退出码记录前结束，因此便携 JSON 只记录启动与关闭请求，不伪造退出码。
- ASAR 内 205 个游戏运行文件 SHA-256 与 v1.0.1 build-manifest 完全一致；归档仅额外含 NOTICE.md、package.json、桌面 main.cjs，共 208 个文件。不含私人项目、凭据、原始会话或测试资料。
- 源工作区内直接运行生成 EXE 曾早退，改在独立临时目录构建并验收。另做中文临时路径对照，Electron 可正常启动；根因未完全隔离，不能归因为通用中文路径故障。

原始结果：result.json、portable-result.json、resources.json。测试用 inspector/CDP 仅由 QA 启动参数开启，正常玩家启动不会开启调试端口。
